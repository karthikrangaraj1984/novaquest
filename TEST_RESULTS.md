## Not executed in this environment

- **Live Claude API calls**: no API key was available in the build workspace. The Claude engine was tested against a local server that speaks the Claude Messages API (request format, model tiers, prompt caching, retries, timeouts, JSON validation, fallbacks, usage caps). Run `ANTHROPIC_API_KEY=… python -m tools.smoke_claude` on your machine to check the live connection.
- **Ollama with a real embedding model**: model downloads were blocked here. The Ollama API integration and pgvector hybrid search were tested with a stand-in Ollama server. On your machine: `ollama pull nomic-embed-text`, then `python -m tools.nq embed`.
- **Docker Compose**: no Docker engine in the build workspace. The same services were run and tested natively with the launcher (`tools/nq.py`); `deploy/docker-compose.yml` is provided but untested.
- **Windows**: no Windows machine in the build workspace. The prerequisites installer's logic (verified downloads, safe unzip, `.env` setup, signature policy, step reporting) passed its unit tests and it builds as a 64-bit Windows program; the launcher's Windows commands and the no-pgvector schema were tested on Linux. The installer and launcher have not yet been run end to end on Windows: do one full run there before the school demo.
